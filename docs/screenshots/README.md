# Screenshots

Place ici les captures d'écran référencées dans le README :

- `carte-principale.png` — screenshot de la carte principale (journal/devoirs/évaluations)
- `carte-historique.png` — screenshot de la carte historique des évaluations
- `carte-moyennes.png` — screenshot de la carte moyennes par matière
- `carte-retours-anticipes.png` — screenshot de la carte retours anticipés
- `carte-agenda.png` — screenshot de la carte agenda scolaire

Format recommandé : PNG, largeur ~500-600px (assez pour être lisible dans
le README sans être énorme). Un simple clic droit → "Enregistrer l'image"
sur ta capture d'écran habituelle suffit, tant que le nom de fichier
correspond exactement à ceux listés ci-dessus.
